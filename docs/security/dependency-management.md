## Dependency Security Policy

1. Dependabot security updates are enabled.
2. Security PRs must pass CI before merging.
3. Critical vulnerabilities receive immediate review.
4. High vulnerabilities receive priority review.
5. AI may analyze vulnerabilities but may not suppress or dismiss security alerts.
6. AI may propose dependency upgrades but may not merge security-related changes without the required approval.
7. Production dependencies receive greater scrutiny than development-only dependencies.
8. Vulnerability exceptions require documented human approval.
9. Exceptions have an expiration/review date.
